02 / 运动与载荷相遇

螺旋运动是 Twist；承受的力是 Wrench

任意刚体瞬时运动都可描述为绕一条轴旋转，同时沿这条轴平移；纯平移是特例。这个运动规律与六维载荷配对，才得到功率与关节驱动力。

再展开：wrench 自己也有一条“中心轴”吗？

当 f ≠ 0，一般 wrench 可以等效为沿某条中心轴的力，以及绕该轴的平行偶力矩。选轴上一点 r₀ = (f × nO)/‖f‖²，定义力学螺距 hF = (f · nO)/‖f‖²，则 nO = r₀ × f + hFf。本实验只有一股作用在 C 的力，故 nO = rOC × f，hF = 0；一般 wrench 还可含独立偶力矩。这个“载荷的轴”和上方选的“运动轴”是不同概念。

03 / 把直觉接到书上

现在再看 Modern Robotics 的符号

下面每一步都对应上方实验中的一个具体动作。先保持参考坐标轴平行，只改变参考点；完整 RNEA 再处理坐标旋转和多连杆。

① 打包六格
𝓕O = [ nx, ny, nz, fx, fy, fz ]T

力矩在前、力在后；两组各用自己的单位。

② 从 C 搬到 O
𝓕O = [ nC + rOC × f ; f ]

平移参考点只改前三个力矩分量；这就是 wrench 坐标变换里叉乘项的来源。

③ 投影到关节
τcomp = − [ a ; 0 ]T 𝓕O = −a · nO

纯转动关节的轴穿过 O、螺距 h = 0，所以 S = [a; 0]。本页 𝓕O 是外部载荷；电机给相反方向的静态补偿。
