01 / 从刚才的观察开始

这些补偿力矩，是怎么算出来的？

先让所有关节静止。没有外部接触，忽略摩擦与弹性，只留下重力。

M(q)q̈ + C(q,q̇)q̇ + g(q) = τ + τext静止：q̇ = 0，q̈ = 0，无外部接触：τext = 0 → τ = g(q)

机械臂伸出去时，后面每根连杆的重量都会作用到上游关节。改变角度，质心与关节轴之间的几何关系改变，所需补偿力矩也随之改变。

试着做：选择一个下游关节，点击“试转 +30°”，同时比较六个关节的参考力矩、当前力矩和变化量。留意自己的角度没动、补偿却变了的上游关节。

实验 01 · YAM 静止悬停独立打开 ↗
这里每次拖动都比较一个新的静止姿态，没有积分运动。青绿色标出输入关节及随动结构，橙色为真实重力。改变输入关节时，会把当前姿态设为新的比较参考；详细计算可在六关节对比下方展开。参数来自模型，不是实机测量。
先预测，再验证

保持上游关节的角度不动，只转动下游关节，上游的重力补偿会不会变？

模型究竟提供了什么？

URDF：质量、局部质心→正运动学：世界质心→重力、力臂、关节轴→各关节的 g(q)

质量、安装方向、负载和重力方向固定后，重力项只随姿态变化。它不需要先计算整个质量矩阵 M(q)。

02 / 从一根杆到两根杆

重量没有变，
变化的是力臂。

从水平线起算角度，逆时针为正。杆先假设没有质量，把质量集中在末端。

两种算法，一个答案

重力向下，关于关节的水平力臂是 ℓ cos q。物理重力矩为负，电机补偿取相反方向。

g(q) = mg₀ℓ cos q力臂法：重量 × 带符号力臂，g₀ = 9.81 m/s²

质点的高度是 ℓ sin q，势能 P = mg₀ℓ sin q。缓慢抬起一个小角度时，电机做功 τ dq = dP，因此：

g(q) = ∂P / ∂q = mg₀ℓ cos q对角度求导使用弧度。均匀杆的质量分布可等效到中点，此时质心距离为 ℓ/2。

再加一个关节

q₂ 相对第一根杆定义，第二根杆相对水平线的角度是 q₁ + q₂。

实验 02 · 两连杆的势能与补偿力矩点质量模型

m₁ = 1 kg，ℓ₁ = 0.35 m，ℓ₂ = 0.30 m；两杆无质量。势能零点取基座高度。

P = (m₁ + m₂)g₀ℓ₁ sin q₁ + m₂g₀ℓ₂ sin(q₁ + q₂)
g₁ = (m₁ + m₂)g₀ℓ₁ cos q₁ + m₂g₀ℓ₂ cos(q₁ + q₂)
g₂ = m₂g₀ℓ₂ cos(q₁ + q₂)

只改变 q₁，两个质量的高度都会变；只改变 q₂，m₁ 的位置不变。所以对势能分别求偏导，就得到两个关节各自的补偿力矩。

展开：从点质量走向真实连杆

真实连杆用质心计算重力势能。若世界 Z 向上：

P(q) = ∑k mkg₀zc,k(q)
gj(q) = ∂P(q) / ∂qj

URDF 的 inertial/mass 给出质量；inertial/origin 的平移部分给出局部质心。用正运动学把质心变换到世界坐标，再计算高度。这正是上一课复杂模型背后的同一件事。

03 / 力、力矩与参考点

一股重力，
为什么需要六个分量？

三个分量描述往哪里推，另外三个描述绕哪根轴转。wrench 把这两种作用放在一起。

力 f · N

一支力箭头在 x、y、z 三根轴上的分量。

力矩 n · N·m

关于指定参考点的转动作用。方向按右手定则表示转轴。

Wrench · [n; f]

Modern Robotics 采用力矩在前、力在后的六维排列。

实验 03 · 改变质心和关节轴独立打开 ↗

先算转动作用，再提取关节分量

O 在关节轴上，r 是从 O 指向质心 C 的向量。所有向量必须用同一组坐标轴表达。

nO = rOC × f
gj = −ajT nOa 是关节正轴的单位向量。这里 n 是真实重力矩，所以电机补偿有负号。

移动参考点，力矩会改变。以质心 C 为参考点时，重力矩为零；移到关节 O 后，需要加上 rOC × f。旋转坐标轴则会改变分量的表达，物理载荷保持相同。

蓝色力矩箭头表示转轴方向，不是另一股推力；实际运动还取决于惯性与关节约束。

展开：RNEA 如何把各根连杆连起来？

前向递推从基座到末端，计算各连杆状态；后向递推从末端到基座，累计本节与后续结构所需的力和力矩。

末端所需 wrench→换坐标、换参考点→加上本节贡献→投影到关节轴

对固定基座、无接触的刚体模型，逆动力学输入 q、零速度、零加速度即可提取 g(q)。书里的实现用虚拟基座加速度 −gworld 计入重力；真实基座仍然静止。这时不再重复添加重力。

gravity_torque = inverse_dynamics(
    q=current_angles,
    qdot=zeros,
    qddot=zeros,
    gravity=[0, 0, -9.81],
    external_wrenches=zeros,
)

这是概念伪代码。Modern Robotics 中的 GravityForces 采用同样的提取思路。求重力时不必先构造关节空间质量矩阵 M(q)。

04 / 从模型到控制

模型负责算，
电机负责出力。

MIT 模式常见的接口是位置、速度、两个增益和前馈力矩。具体单位、量程与正方向需遵循对应驱动器定义。

τ = Kp(qd − q) + Kd(q̇d − q̇) + τff这里用关节侧一致单位理解。MIT 模式不会自行读取 URDF 并计算整条机械臂的重力。

上位机读取当前实际 q，计算 ĝ(q)，把结果作为前馈力矩发送。电机端同时执行位置、速度误差反馈。下面忽略摩擦补偿，先看最基础的形式。

编码器：q、q̇→上位机：ĝ(q)→MIT：PD + 前馈→机械臂运动
模式Kp / Kd目标行为
拖拽Kp = 0，Kd 适量q̇d = 0托住重量，允许人手推动，提供阻尼
保持姿态Kp > 0，Kd > 0固定 qd，q̇d = 0受力偏离后，产生拉回目标的力矩
轨迹跟踪Kp > 0，Kd > 0随时间更新 qd、q̇d跟随规划轨迹

拖拽模式的力矩从哪里来？

τmotor = ĝ(q) − Dq̇

假设补偿准确，忽略摩擦，代入真实动力学后：

M(q)q̈ + C(q,q̇)q̇ + Dq̇ = τhand

电机托住重量，惯性和速度相关作用仍然存在。人手通过机械结构直接施力，基础拖拽不要求先测到手的外力。另一条实现路径是测量或估计外力，再由导纳模型生成运动指令。

低速 ≠ 低加速度。慢速、平滑运动时可以先不显式补偿惯性与科氏／离心项；突然启动或停止仍会产生惯性力矩。相同平滑轨迹用两倍时间完成，两类动态项均缩小到约 1/4，重力保持不变。
展开：对照 I2RT/YAM 的实际实现

固定版本源码中，_compute_gravity_compensation() 调用 MuJoCo 逆动力学，并将速度、加速度输入设为零；enter_gravity_comp_idle() 清零活动指令后设置拖拽用 kd。更新循环还可加入摩擦补偿和逐关节重力比例。

传入算法的零速度用于提取重力项，实际机械臂此时可以正在运动。对应来源见资料页。

模型偏差与摩擦

使用平滑库仑摩擦 τf = f₀ tanh(q̇ / 0.03)。它不模拟严格的静摩擦停滞。

速度 / rad·s⁻¹0.00

重力补偿需求 / N·m0.00
m = 2 kg，ℓ = 0.35 m，杆无质量，末端点质量，I = mℓ² = 0.245 kg·m²。角度从水平线逆时针起算。切换模式会复位并暂停；参数为教学值。此理想模型无关节限位、碰撞或电机饱和，不连接硬件。

按这个顺序，做四次实验

  1. 选择“无电机力矩”，开始运行：观察重力如何让杆落下。
  2. 选择“仅重力补偿”：先观察静止，再点“给初速度”。重量被抵消，已有运动仍然存在。
  3. 选择“补偿＋阻尼”，施力后松手：关节逐渐停下，没有拉回旧位置的弹簧。
  4. 选择“补偿＋PD”，施力后松手：关节偏离目标，然后回到目标附近。减小 Kp，看看同样的力矩能推开多远。
τmotor = ĝ(q) + Kp(qd − q) − Kdq̇目标速度为零。静态、精确补偿且无摩擦时：τhand = Kp(q − qd)。

例如 Kp = 10 N·m/rad，持续施加 1 N·m，理想静态偏移是 0.1 rad，约 5.73°。Kd 改变到达平衡的过程，不改变这个静态偏移。

展开：实验实际积分的是什么？
I q̈ = τmotor + τhand − mg₀ℓ cos q − τf

这是点质量摆杆的完整运动方程。使用四阶 Runge–Kutta 积分，子步长不大于 1/240 s。控制器只选择补偿部分项，真实模型里的惯性一直保留。

motor = gravity_feedforward + position_feedback + damping
acceleration = (motor + hand - gravity - friction) / inertia
state = rk4_step(state, acceleration, dt)

基本模式下摩擦设为零、重力比例为 1。把补偿比例改成 0.9，再看拖拽模式，会看到残余重力造成漂移。

目前得到的是关节空间柔顺。多个关节组成机械臂后，末端的方向性手感还取决于姿态与 Jacobian。基础拖拽没有位置弹簧，并不保证松手后毫米级锁定位置。任务空间阻抗可以作为下一辑。

  • YAM 重力：力矩计算与势能中心差分梯度相互核对，另检查下游总质心等效与关节轴投影。

  • 网页：检查章节深链接、滑块、模式切换、离线资源、移动端布局与项目子路径。
